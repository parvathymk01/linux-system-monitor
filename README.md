# Linux System Monitor

## Overview

Linux System Monitor is a command-line application written in C that displays important system information by reading Linux system files and using standard Linux APIs.
---

## Planned Features

- System Information
- CPU Information
- CPU Usage
- Memory Usage
- Disk Usage
- System Uptime
- Running Processes
- Logged-in User
- IP Address
- Live Refresh

---

## Technologies

- C
- GCC
- Make
- Linux System Calls
- /proc Filesystem
